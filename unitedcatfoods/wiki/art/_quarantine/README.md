# Quarantined reference material

These plates derive from Billy Meier / FIGU "beamship" material (the
Meier sheet names FIGU / Semjase in its own artwork). That family is
qualitatively different from the U.C.F.-native Loaf plates: it
references a real organisation's imagery and symbol set, which makes it
unsuitable for anything commercial-facing without specific clearance.

The underscore directory is deliberate: GitHub Pages (Jekyll) does not
serve underscore-prefixed paths, so nothing in here is reachable from
the published site. Kept rather than deleted because they are part of
the project's design history; git history has them either way.

If a U.C.F. scout craft is ever wanted, it gets designed as an original
hull, not adapted from these.

Additional legacy plates are kept here when they conflict with the current
tone guide. The former home-page café raster and its source contained baked
signage and redrawn badges; the cyber-operative portrait pushed the world into
neon/cyberpunk mascot territory. They remain available as design history but
are no longer served or referenced by the public site.
