Sloth

The calm, observant network monitor.
Open source

A passive network SIGINT console for Linux, written in C99 from the kernel-facing code up. Twenty-seven live ncurses views: 802.11 beacon, probe and deauth sniffing, ARP / mDNS / NBNS / DHCP / SSDP device discovery, TLS ClientHello and JA3 fingerprint capture, and six alert rules for port scans, deauth floods, NXDOMAIN bursts and periodic beaconing. It never injects, never scans and never modifies kernel state — it only watches, and writes JSONL plus a per-alert pcap for whatever comes next.

The native app the command-line generator grew into, in a Shōwa-era game-show register. How all seventeen are built.

Not dogma — a set of trade-offs made deliberately, and made the same way every time.

01 · Native

Compiled, not wrapped

C, Swift, Kotlin and Elixir over Flutter, React Native or Electron. Smaller binaries, lower battery cost, direct platform APIs, no framework treadmill.

02 · Tested

Tests are the contract

Unit-test parity across platforms, audited rather than assumed. Drift is logged and fixed, never papered over.

03 · Unencumbered

Dependencies you can defend

Platform frameworks first — the shipping apps carry none at all. Where a library earns its place, the reason is written down and audited.

04 · Private

Data stays on device

Encrypted vaults, no silent network, no analytics. Privacy as an architecture decision rather than a policy page.
