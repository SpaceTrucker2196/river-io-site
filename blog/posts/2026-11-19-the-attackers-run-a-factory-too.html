The attackers run a factory too

Agents found critical bugs in NGINX and OpenJDK in hours this week. Attackers poisoned an agent library and ran agent fleets. The patch window is now short.

This brief covers 17 to 19 November 2026. We found four new items, all dated 17 or 18 November. We also add one research paper from 12 November that we did not cover before. The theme is speed. Agents now find and exploit bugs faster than a normal patch cycle. Attackers also use agents, and they target the build pipeline.

One hour to find, two hours to exploit

Oracle patched Java4Shell on 17 November 2026. The bug is CVE-2026-114938. Its CVSS 4.0 score is 9.2, which is critical. CVSS is the standard score for how bad a vulnerability is.

The bug is in the OpenJDK Base64 decoder for x86-64. A malformed input tail makes the decoder write 64 bytes out of bounds. An attacker can use this to leak heap data or to run code.

Calif published the write-up. Researcher Quang Luong used OpenAI Codex to audit the HotSpot code. Codex found the bug in about an hour. A working exploit took about two more hours. The total token cost was under $200.

The write-up includes a standalone reproducer. The reproducer prints “REPRODUCED” on an affected JDK. That is the right shape for an agent finding: a claim plus a test that proves it.

Ten NGINX bugs, found by five teams

F5 published an out-of-band notice for open source NGINX on 18 November 2026. It covers 10 CVEs. We read The Register article from the same day. We did not open the F5 advisory.

CVECVSSWhat went wrong
CVE-2026-1236339.2Use-after-free. NGINX frees a connection's memory while a request still needs it.
CVE-2026-1230079.2Wrong flow-control accounting causes an invalid memory copy. Present since NGINX 1.9.5 (2015).

Both bugs allow remote code execution with no login. Both need HTTP/2 to be on. NGINX 1.31.9 fixes them. F5 says it has no evidence of exploitation.

Wiz, Ikotas Labs, Metnir, Rapid7 and Xint found the bugs independently. The Register says “most, if not all” had AI help. The article does not name the tools or models.

Xint says a researcher found CVE-2026-123007 first. A few days later, a fully automated Xint scan found four more bugs with no human guidance. Xint chained NGINX bugs and a Linux kernel bug into a root exploit. Rapid7 published a proof of concept.

Five teams found the same critical bugs at the same time. AI discovery is now normal.

A poisoned agent library

Wiz reported a supply chain attack on 17 November 2026 and updated it on 18 November. A supply chain attack puts malware into a package that other people install. The package is agent-framework, the Microsoft Agent Framework on PyPI.

Versions 1.26.1 and 1.26.2 were malicious. The attacker published them at 20:35 UTC and about 21:08 UTC. Both were gone by about 21:30 UTC. Wiz says the attacker appears to have held a certificate and key for Microsoft's own signing and publishing pipeline. Wiz does not know how.

The payload ran each time Python started in that environment. It ran even if no code imported the package. It took environment variables and credential files for Azure, npm, pip, git and Docker. It also took GitHub Actions OIDC tokens. An OIDC token lets a CI job prove its identity to a cloud account.

Wiz tells users to pin version 1.26.0 and to rotate every secret on affected hosts and runners. Any workflow that ran 1.26.2 with id-token: write must treat its tokens as exposed. A vendor signature did not make the package safe.

An attacker with 39 agent workers

SOCRadar published an analysis on 18 November 2026. It describes a campaign against PHP2Shell, a PHP bug from October. Our 27 October brief covered the bug. The campaign is new.

The operator built an orchestrator that queued targets. It ran 39 agent workers in parallel on self-hosted DeepSeek V4.1 models. The agents ran exploits, kept access and collected credentials. They hit 595 IP addresses in 57 countries.

SOCRadar confirmed 404 compromised hosts. The agents took about 290,000 files, or 9.5 GB. They also copied the operator's own lab by mistake. SOCRadar calls the campaign “human-directed and AI-augmented.” It found no evidence of full autonomy.

This attacker used the same shape as a software factory: one orchestrator and many workers. Exposed hosts got hit within hours of a public proof of concept.

A CEO names the factory

Satya Nadella spoke at DealBook on 18 November 2026. TechCrunch reported it. He described the team that builds Cowork, the agent in Microsoft 365 apps. The team has 11 developers.

He said: “They build a software factory that builds the product.” This is a statement, not a metric. He gave no output numbers.

Make the agent list its choices

Ruixin Wang and Tianyi Zhang submitted a preprint to arXiv on 12 November 2026. They name a failure mode called specification satisficing. An agent finds a choice that meets the task. It then picks a different choice that does not meet the task, because its own reason seems good enough.

Their fix has two steps. First, the agent reports each implementation choice and its reason. Second, a check compares each choice with the task description. The average pass@1 gain was 5.09% on DeepSWE. It was 7.06% on the hard subset of SWE-bench Pro. Pass@1 is the share of tasks the agent solves on the first try.

The OpenAI page did not load for us, so we did not use the figure. We also skipped a Copilot Fusion benchmark score and two model launches. Those are vendor product news.

What it means for the River.io Software Factory

Our zero third-party dependency rule closed the door this attack used. The agent-framework payload needed a job that installs a package it does not own. Our native compiled repos install nothing. Any helper job that must install a package will pin the exact version and hash.

We will treat CI identity as a secret. Every GitHub Actions workflow will set read-only permissions by default. Only a deploy job gets id-token: write. We will open one issue per repo for this audit.

We will audit our own native code with an agent. Attackers can now do this in hours. Each finding must include a reproducer test that fails. A finding without a failing test does not enter the backlog.

We will measure patch speed. Any host that runs NGINX with HTTP/2 gets 1.31.9 now. If it cannot upgrade, we turn off HTTP/2. METRICS.md gets a new row: hours from upstream patch to deployed patch.

Our pull request template gets a new section: “Implementation choices and why.” The reviewer checks each choice against the issue text. This adds no dependency.

CareTime, TimeForCare and MaterialsAndPractices handle regulated data. They stay at human-gated autonomy. An agent can propose CI permission changes there. A named human approves them.

We will run the agent audit and the new template section on sloth first. Sloth parses untrusted radio frames in C, so it is a good target. We will record findings, false positives and review minutes for two weeks.
