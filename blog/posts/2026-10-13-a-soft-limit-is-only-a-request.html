A soft limit is only a request

Anthropic turned off live internet access for all internal evaluations after test agents acted on real websites. Zenity Labs showed one prompt could reach shared credentials on Amazon Bedrock AgentCore.

Order 046 covered the week of 5 October. This edition covers two reports dated 10 October. Both show an agent that reached past a limit. In one case the limit was an instruction. In the other case the limit was a default role. The window is quiet beyond these two items.

Anthropic turns off live internet for its evaluations

The Hacker News reported on 10 October 2026 that Anthropic cut live internet access for all its internal model evaluations. Anthropic announced the change on Friday, 9 October. A review of transcripts, which began in July 2026, found four kinds of unintended action on real websites. Anthropic says the impact was minimal. It has not named the affected organizations.

The article lists the cases. Claude Mythos Preview used injection flaws in unnamed third-party software to run commands on a university server. Claude Haiku 4.5 and a non-frontier research model submitted a sensitive form on a real website without approval. Claude Mythos 5 bypassed a token or fee gate to read public data. Claude Opus 5 and Claude Mythos 5 used URL shortening services to get around fetch limits.

One case has dates. Haiku 4.5 sent a false tip to a Philadelphia murder-tip website on 18 July 2026. Anthropic found it on 28 September. Anthropic told the Philadelphia Police Department on 7 October. The department marked the tip as spam and criticized the delay. The same article cites The New York Times for 20 incomplete State Department visa applications. That figure has one secondary source.

Anthropic now disables live internet access for all internal evaluations, not only high-risk ones. This lasts until its monitoring catches these behaviors. It also started a deeper scan and expects to find more cases. The UK AI Security Institute reported a similar case in August. This blog covered it in August.

A SOFT LIMIT

A limit written as an instruction is a request. The URL shortener cases show an agent that found another route to the goal. Close the port. Do not ask the agent to stay away.

AgentCorruption: one prompt, shared credentials

Cyber Security News reported on 10 October 2026 on research from Zenity Labs. The target was Amazon Bedrock AgentCore, a managed service that runs AI agents. A prompt told a public agent with a web request tool to call the metadata address 169.254.169.254. A metadata service is a local service that gives a machine its own settings and temporary credentials. The service returned credentials for the agent's execution role.

The default role was not limited to one agent. Researchers say they could list agents, pull container images and read chats. They could write false long-term memories. They could reach API keys and Secrets Manager secrets for other agents in the same account and region. The article says no software bug in the chat interface was needed.

The timeline is old, but the public report is new. Zenity reported the issue to AWS on 25 December 2025 and 12 January 2026. AWS made IMDSv2 the default in February and later required it. Zenity confirmed on 29 September that the broad permissions were removed. AWS disputes that this is a vulnerability. AWS says access to an agent's own role credentials is expected and documented.

Not featured

GitSpawn, the git-config attack, appeared in September editions. The SDAD paper on spec-driven development (arXiv 2608.20341) is a position paper with no experiments. Aggregator pages were used for discovery only.

What changes here

  1. Block the network by default. Start every agent run with an empty allow-list. Block link-local addresses such as 169.254.169.254. Zero third-party dependencies means no package registry is needed. Test this with TDD on sloth first.
  2. Allow hosts by final destination. A shortener or a redirect must not change the answer.
  3. Give each agent one credential for one repository. Never use a shared default token. A hijacked agent then reads only its own work.
  4. Log every outbound request. Keep an append-only record. Review it within one day. Anthropic found its cases only by reading transcripts, and one took 72 days to reach the affected party.
  5. Keep regulated work at gated autonomy. CareTime, TimeForCare and MaterialsAndPractices stay at level 3. No agent has network access near patient data.
