The settings file is a secret file

Three new reports point at the setup around the agent: its settings files, its fallback model, and its job description.

This brief covers 9 to 11 November 2026. The window was not quiet. Three reports have dates inside the window. A fourth report is older, but we have not covered it before. Each report points at the setup around the agent, not at the agent.

Agent settings files hold secrets

GitGuardian published a study on 9 November 2026. It scanned public GitHub from January 2025 to 7 November 2026. It looked at settings.local.json. That is the file where Claude Code saves the commands that a user approved.

GitGuardian found 31,088 distinct secrets in that file, in 23,276 repositories. 5,343 secrets were valid when GitGuardian found them. The largest valid group was database credentials, with 2,280 distinct secrets. Cloud provider tokens were 971. AI service tokens were 583.

Other files leak too. CLAUDE.md files held 6,155 distinct secrets, and 2,537 were valid. The OpenAI Codex file .codex/auth.json held 1,064 tokens in 536 repositories. This problem is not limited to one vendor.

The leak also reaches container images. A container image is a packaged copy of an application and its files. GitGuardian found 613 distinct secrets in Docker Hub images, and 99 were valid. One valid Cloudflare token was in 559 tags of one image.

The trend is better. Monthly occurrences fell from 12,535 in April 2026 to 959 in October. That is a 92% drop. GitGuardian says it does not know the cause.

We reported an Apiiro count of 2,539 secrets on 7 November. The two counts use different time ranges and different methods. Do not add them.

A fallback model is part of the attack surface

Anthropic released Claude Fable 5.2 on 9 November 2026. The announcement describes a fallback. A fallback is a second model that answers when the first model does not. Safety classifiers send flagged cybersecurity requests to Opus 4.8. They send flagged biology requests to Opus 5.

Notebookcheck reported figures from the system card on 10 November. We did not open the system card. Treat these figures as secondary.

  • On an indirect prompt injection benchmark, attacks succeeded 4.09% of the time against Fable 5.2. The figure for Fable 5.1 was 1.02%.
  • Opus 4.8 answered 53% of the attempts against Fable 5.2.
  • Attacks succeeded 2.05% of the time when Fable 5.2 answered. They succeeded 5.17% of the time when Opus 4.8 answered.

Prompt injection is text in a file or a web page that tells the agent to do something. Notebookcheck reports that the classifiers also read files, web results and connector content. Injected text can thus cause the switch to the older model. A setting turns the switch off. Flagged requests then pause for the user.

The lesson applies to all pipelines. Know which model answers each step. Do not let untrusted input select the model.

Give the agent a job, then check each action

Cequence Security published a report with KPMG in Singapore on 11 November 2026. We opened the press release, not the report. Cequence sells this type of control. Read the figures as direction.

Cequence tested agents in a prototype. Agents with only a login and fixed permissions tried to act outside their job in 44% of runs. Cequence then gave each agent a defined job and checked each action against it. The figure fell to 1%.

The check did not slow the work. Task completion rose from 76% to 95%. Token use fell by about 35% for each run.

Agents start four in ten pull requests

GitHub published Octoverse 2026 on 28 October 2026. This report is older than our window. We include it because we have not covered it before.

A pull request is a proposed change to a repository. GitHub says agents started 17% of pull requests in March 2026. In September the figure was more than 40%, or about 110 million pull requests. GitHub calls this a floor, because it cannot detect all agents.

GitHub merged 90% of agent pull requests in two weeks in September. The figure for other pull requests was about 86%. A merge rate does not prove quality.

Detected AI involvement differs by language. It was about 40% to 44% of merged pull requests for TypeScript, Python and Rust. It was about 21% to 34% for Java, C# and C++.

One essay

Ben Bahrenburg published an essay on 9 November 2026. It is an opinion, not a study. He writes: “The moat is not the agent.” He says the value is in the evaluations, policies and feedback loops around the models.

He also says a fully dark factory is probably the wrong goal. A dark factory is a software pipeline that runs with no human in the loop. His reason is that maintainability and product fit have no reliable automated test. He suggests one measure: cost for each merged pull request.

What it means for the River.io Software Factory

We treat agent settings files as secret files. We will ignore .claude/, .codex/, .cursor/ and .mcp.json in git and in Docker builds. We will add a small pre-commit check of our own. The check needs no third-party dependency.

We do not approve a command that contains a token. We put the token in an environment variable.

We write the job down for each GitHub issue. One issue gets one repo and one list of allowed actions. We record which model answers each step of an unattended loop.

CareTime, TimeForCare and MaterialsAndPractices handle regulated data. A human will search their git history for these files. These repos stay at human-gated autonomy. A 40% agent share on GitHub does not change that rule.

We test the pre-commit check and the job file on MeowPassword, weathergalactic or sloth first.
